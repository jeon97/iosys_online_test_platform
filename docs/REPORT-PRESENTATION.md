# 수험표 출력 데이터 처리

시험 접수부터 결과·증명서 발급까지의 기능 개발·개선에 참여하였습니다. 수험표에서는 시험 종류별 응시·면제 표시를 구성하고 사진과 약도 자료를 리포트에 연결하였습니다.

## 처리 방식

1. 시험 유형과 응시 구분을 읽고 해당 유형에 응시·면제 선택 표시를 적용하였습니다.
2. 사진 파일이 존재하면 출력 데이터에 연결하고 없으면 사진 값을 비웠습니다.
3. 약도 파일 경로가 있으면 해당 파일을 확인하였습니다. 경로가 없는 경우에만 약도 URL을 사용하였습니다.
4. 구성한 데이터를 시험 유형별 리포트 양식에 전달하였습니다.

## 코드 예제

리포트에 전달할 표시값을 구성하는 예제입니다. 가상의 자료 ID와 존재 확인 함수를 사용합니다.

| 입력 | 출력 |
|---|---|
| 면제 표시를 사용하는 시험·면제자 | 면제 항목 선택 표시 |
| 별도 시험 유형 | 입력 표시값 유지 |
| 사진 파일 없음 | 사진 제외 |
| 약도 파일과 URL 모두 존재 | 파일 우선 |
| 약도 파일 경로 없음 | URL 사용 |
| 약도 경로는 있으나 파일이 없음 | 약도 제외 |

면제 자격·합격 여부의 판정과 실제 리포트 렌더링은 포함하지 않습니다.
