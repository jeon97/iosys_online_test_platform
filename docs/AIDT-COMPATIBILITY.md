# AIDT 접근성·호환성 검토

AIDT 문항 저작·표현 기능 개선 업무에 참여하고, 브라우저와 운영체제에서 제공하는 접근성 기능을 조사하여 비교 자료로 정리하였습니다. 화면 읽기, 확대·축소, 고대비, 키보드 탐색, 음성 읽기와 자막을 검토 항목으로 나누었습니다.

본인 이름이 포함된 보관 문서에서는 브라우저와 운영체제의 지원 기능 조사 및 비교표를 확인하였습니다. 실제 서비스의 모든 환경을 실행하여 통과 판정한 테스트 보고서로 해석하지 않았습니다. 원본 코드의 개인별 문항 유형 수정 이력은 이번 검토에서 확보하지 못하였습니다.

## 진행 방식

브라우저 기능, 운영체제 기능, 확장 도구를 구분하여 문항 화면에서 활용할 수 있는 지원 수단을 정리하였습니다. 지원 여부를 확정하지 못한 항목은 추가 확인 대상으로 남겼습니다. 이 자료를 바탕으로 호환성 검토에서 확인해야 할 항목을 구체화하였습니다.

아래 표는 채용 검토용으로 새로 작성한 점검 예시입니다. 과거 서비스의 실제 테스트 결과나 현재 브라우저 지원 현황을 나타내지 않습니다.

| 점검 주제 | 확인할 동작 | 기록 예시 |
|---|---|---|
| 키보드 탐색 | 문항 진입 → 보기 이동 → 선택 → 다음 문항 이동 | 단계별 포커스 위치와 선택 결과 |
| 확대·축소 | 문항·보기·제출 버튼의 겹침과 잘림 확인 | 확대 비율·화면 크기·재현 단계 |
| 화면 읽기 | 문항 내용과 보기 이름·선택 상태 확인 | 도구명·읽기 순서·누락 항목 |
| 음성·자막 | 서비스 기능과 브라우저 보조 기능을 각각 확인 | 사용 기능·확인 범위·미확인 항목 |

기능 지원 조사와 실제 화면 시험을 구분하였습니다. 접근성 인증 취득이나 전체 브라우저 호환성을 보장하였다는 성과는 기재하지 않았습니다.

ClassRoom의 요청 시나리오와 서버 모니터링은 별도의 [JMeter·Scouter 부하 시험](PERFORMANCE-TEST.md)에서 설명하였습니다.
