# 온라인 평가·오답노트 외부 API

온라인 평가 시스템과 고객사 홈페이지를 연결하는 API를 개발하였습니다. 인증, 시험 조회, 응시 화면, 성적과 오답노트를 처리하였으며 외부 시스템 운영자와 요청·응답 규격을 협의하였습니다.

## 담당 기능

| 영역 | 주요 기능 |
|---|---|
| 인증 | 사용자 정보 검증, 인증 토큰 생성, 회원 여부 확인 |
| 모의평가 | 목록, 응시 화면, 이력, 채점지, 성적표, 전체·오답 다시 풀기 |
| 자율평가 | 분류 조회, 응시 화면, 이력 조회 |
| 오답노트 | 목록·분류, 즐겨찾기, 휴지통 이동·복원, 초기화 |
| 오답 다시 풀기 | 출제 범위, 시험 생성, 이력 조회·삭제 |
| 홈페이지 연계 | 과정 목록과 회원 확인 요청 |

개발 업무 기록은 약 30개 API이며 V1.2 명세의 계약 범위는 제공 21개·사용 2개입니다.

## 코드 예제

ExternalAssessmentService는 인증 사용자와 시험·오답노트 데이터를 연결합니다. 사용자 일치 검사, 오답노트 상태 전이와 요청 ID 중복 처리는 예제의 추가 규칙입니다.

- 토큰 사용자와 요청 사용자 확인
- 응시 가능 시험 목록 반환
- 오답노트 상태 변경
- 같은 요청 ID의 반복 변경 방지
