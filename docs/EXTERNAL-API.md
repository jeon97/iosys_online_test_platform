# 온라인 평가·오답노트 외부 API

온라인 평가 화면과 고객사 홈페이지를 연결하기 위해 인증, 시험 조회, 응시 화면, 성적, 오답노트 API를 설계하고 구현하였습니다.

본인 설명은 약 30개 API 개발입니다. 보관 V1.2 명세 기준으로 이전에 정리한 계약은 제공 21개·사용 2개, 총 23개입니다. 두 수치의 집계 범위 차이는 확인되지 않았으므로 동일한 수치로 합치거나 내부 호출 수로 보정하지 않습니다.

## 담당 범위

| 영역 | 주요 기능 |
|---|---|
| 인증 | 사용자 정보 검증, 인증 토큰 생성, 회원 여부 확인 |
| 모의평가 | 목록, 응시 화면, 이력, 채점지, 성적표, 전체·오답 다시 풀기 |
| 자율평가 | 분류 조회, 응시 화면, 이력 조회 |
| 오답노트 | 목록·분류, 즐겨찾기, 휴지통 이동·복원, 초기화 |
| 오답 다시 풀기 | 출제 범위, 시험 생성, 이력 조회·삭제 |
| 홈페이지 연계 | 과정 목록과 회원 확인 요청 |

## 구현 범위와 공개 재작성

인증·시험 조회·응시 화면·성적·오답노트·홈페이지 연계의 업무 범위를 정리하였습니다. 아래 공개 코드는 이 업무를 설명하도록 독립 작성한 예제이며, 토큰 사용자 일치 검사·소유권 재확인·요청 ID 멱등성의 전체 규칙이 원본에 적용되었다고 주장하지 않습니다.

## 공개 예제

[ExternalAssessmentService](../samples/exam-workflow/src/main/java/com/portfolio/exam/api/ExternalAssessmentService.java)는 다음 규칙을 추가한 공개 설계 예제입니다.

- 토큰의 사용자와 요청 사용자의 불일치 차단
- 응시 가능한 시험만 반환
- 오답노트 상태 전이 검증
- 요청 ID를 이용한 중복 변경 방지

실제 URL, 토큰 형식, 고객사 코드, 원본 DTO와 쿼리는 포함하지 않았습니다.
