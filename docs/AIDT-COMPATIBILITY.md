# AIDT 접근성·호환성 검토

AIDT 문항 저작·표현 기능 개선에 참여하였습니다. 브라우저와 운영체제의 접근성 지원 기능을 조사하고, 문항 화면에서 활용할 기능을 비교표로 정리하였습니다.

## 검토 내용

| 항목 | 검토 내용 |
|---|---|
| 화면 읽기 | 브라우저·운영체제별 화면 읽기 도구와 호환 관계 |
| 확대·축소 | 브라우저 확대와 운영체제 돋보기 기능 |
| 고대비 | 운영체제 설정과 확장 프로그램 지원 |
| 키보드 탐색 | 포커스 이동과 선택 동작 |
| 음성·자막 | 음성 읽기, 음성 인식과 자막 지원 |

브라우저 자체 기능, 운영체제 기능과 확장 도구를 나누어 비교하였습니다. 지원 여부가 불명확한 항목은 추가 검토 대상으로 남겼습니다. 이 자료는 지원 기능 조사이며 서비스 화면의 환경별 통과 결과는 아닙니다.

## 화면 점검 항목 예시

- 키보드로 문항 진입·보기 이동·선택·다음 문항 이동
- 확대 상태에서 문항·보기·제출 버튼의 겹침과 잘림
- 화면 읽기 도구의 문항·보기·선택 상태 전달
- 음성·자막 기능의 적용 범위
