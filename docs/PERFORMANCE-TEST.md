# ClassRoom JMeter·Scouter 부하 시험

온라인 수업·평가 요청을 JMeter로 반복 실행하고 Scouter로 응답시간, CPU, 메모리와 SQL 시간을 확인하였습니다. 사용자별 세션을 분리하고 로그인 이후 목록·상세·파일 요청을 사용 순서에 맞춰 구성하였습니다.

## 시험 조건

- CSV 데이터를 이용한 사용자별 세션 분리
- 정적 리소스 포함 여부 비교
- HTTP 압축 여부 비교
- 애플리케이션 스레드 수와 로그 수준 변경
- 요청 수·평균·최대 응답시간·오류율·처리량 수집

## 측정 결과

로컬 시험 환경에서 조건별로 측정한 결과 범위입니다.

| 동시 사용자 | 요청 수 | 평균 응답시간 | 오류율 | 처리량 |
|---:|---:|---:|---:|---:|
| 40명 | 400 | 639~826 ms | 0.00~0.17% | 38~45 req/s |
| 100명 | 1,000 | 2,290~3,128 ms | 6.87~9.06% | 26~34 req/s |

100명 조건에서 응답시간과 오류율이 증가하였습니다. 스레드 수를 늘렸을 때의 처리량, 압축 여부와 로그 설정에 따른 응답 차이를 비교하였습니다. Scouter에서 요청별 SQL·외부 호출시간과 CPU·메모리를 함께 확인하였습니다.

이 결과는 해당 시험 환경의 측정값이며 운영 서버의 수용 인원은 아닙니다.
