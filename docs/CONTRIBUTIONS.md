# 담당 업무와 기여 내용

SVN 작업 사본에서 작성자 `joshuajeon`으로 확인되는 변경 파일과 실제 코드 구조를 기준으로 정리했습니다. 원격 SVN 로그가 안정적으로 조회되지 않아 커밋 수는 기재하지 않았습니다.

## 시험 운영 시스템

시험 접수 이후 운영자가 확인하는 배정·응시·결과 영역을 개발했습니다.

### 시험계획과 배정

- 시험계획과 시험실 운영 정보 조회
- 시험장 배정 여부 확인
- 수험번호와 좌석번호 배정 상태 관리
- 시험 데이터 정합성 확인 기능

### 응시자 기능

- 응시 예정 시험과 응시 완료 시험 조회
- 시험 안내 및 응시 결과 화면
- 이의신청과 답안 공개 관련 화면
- 사용자 인증 필터와 접근 경로 처리

### 결과와 통계

- 시험 결과 통계와 상세 결과 조회
- 부정행위 의심 데이터 통계
- 접수 및 자격 확인 현황 집계
- 자격증 출력 이력 조회
- 운영 자료 엑셀 생성

## 문항 관리 시스템

문항이 만들어져 시험에 사용되기까지의 계획과 위원 작업 흐름을 개발했습니다.

### 출제·검토 계획

- 출제 및 검토 계획 등록·수정·조회
- 분야별 필요 문항 수와 문항 유형 관리
- 출제 요청과 검토 요청 상태 처리
- 검토 자료 첨부파일 관리

### 위원 배정과 문항 선정

- 출제·검토·선정위원 배정
- 선정 대상 문항과 배정 현황 조회
- 선정 작업 진행 현황과 결과 통계
- 문항 이동과 시험 사용 관계 관리

### 문항 통계와 관리자 기능

- 문항별 사용 이력과 사용 통계
- 분류, 코드, 메뉴 관리
- 시스템 처리 이력 조회

| 프로젝트 | 파일 수 | 주요 영역 |
|---|---:|---|
