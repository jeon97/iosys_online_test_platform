# 수험표의 응시 구분과 출력 데이터 구성

접수부터 결과·증명서 발급까지의 기능 개발·개선에 참여하였습니다. 수험표 출력 원본에서는 시험 종류에 따라 1차 응시·면제 표시를 구성하고, 사진과 약도 자료를 확인한 후 리포트에 전달하는 흐름을 확인하였습니다.

경력기술서의 출력 기능 담당 설명과 현재 원본을 대조하였습니다. 관련 합격확인서 화면에는 본인 SVN 수정 정보가 있으나, 아래 출력 Service 메서드의 개인별 전체 변경 이력은 확보하지 못하였습니다. 따라서 이 사례는 담당 업무의 현재 원본 동작을 설명하며 해당 메서드 전체의 단독 작성 증거로 제시하지 않습니다.

## 구현 과정

1. 시험 유형과 응시 구분을 읽고, 해당 유형에만 응시·면제 선택 표시를 적용하였습니다.
2. 사진 경로가 있는 경우 파일 존재 여부를 확인하고, 파일이 없으면 사진 값을 비웠습니다.
3. 약도 파일 경로가 있으면 해당 파일을 확인하였습니다. 경로 자체가 없는 경우에만 약도 URL을 사용하였습니다.
4. 구성한 데이터를 시험 유형별 리포트 양식에 전달하는 흐름으로 처리하였습니다.

공개 예제는 리포트 엔진에 전달하기 전의 데이터 구성만 재작성하였습니다. 파일 경로는 가상의 자료 식별자로 바꾸고 존재 확인 함수를 주입하였습니다. 회사 리포트 양식·직인·사진·실제 URL은 포함하지 않았습니다.

| 설명용 입력 | 출력 |
|---|---|
| 면제 표시를 사용하는 시험·면제자 | 면제 항목 선택 표시 |
| 별도 시험 유형·면제 값 | 입력 표시값 유지 |
| 등록한 사진 파일 없음 | 사진 제외 |
| 약도 파일 있음·URL도 있음 | 약도 파일 우선 |
| 약도 경로 없음·URL 있음 | URL 사용 |
| 약도 경로는 있으나 파일이 사라짐 | 약도 제외; URL로 자동 대체하지 않음 |

마지막 분기는 원본의 조건을 그대로 설명한 것입니다. 공개 코드에서도 이를 임의로 보완하지 않았습니다. 이 예제는 면제 자격을 판정하거나 합격 여부를 계산하는 기능이 아닙니다.
