# 시험 준비 점검과 좌석 배정

시험 시작 전에는 접수 데이터, 시험장 수용 인원, 좌석 중복을 먼저 확인해야 합니다. 담당 화면에서는 시험 데이터 점검, 시험장·시험실 배정, 수험번호와 좌석 배정을 하나의 준비 단계로 다뤘습니다.

## 처리 기준

1. 접수자에게 시험 종목과 시험 일정이 지정됐는지 확인합니다.
2. 시험실 정원보다 많은 인원을 배정하지 않습니다.
3. 같은 시험실의 좌석 번호와 수험번호가 겹치지 않게 합니다.
4. 이미 같은 자리에 배정된 요청은 다시 저장해도 결과가 바뀌지 않게 합니다.
5. 다른 자리로 이동할 때는 이전 배정을 덮어쓰지 않고 변경 이력을 남깁니다.

공개 예제는 [ExamReadinessService](../samples/exam-workflow/src/main/java/com/portfolio/exam/readiness/ExamReadinessService.java)에 있습니다. 실제 테이블명, 수험번호 규칙과 고객사 데이터는 포함하지 않았습니다.
