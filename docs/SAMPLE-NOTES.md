# 코드 예제 안내

이 저장소의 코드는 업무 처리 흐름을 별도로 구현한 예제입니다. 아래 추가 규칙은 예제에만 적용하였습니다.

| 기능 | 업무 구현 | 예제의 구성·추가 규칙 |
|---|---|---|
| 통계 조회 | 검색 조건별 건수·시험 정보·응시자 목록 조회 | 페이지 크기 상한과 범위를 벗어난 페이지 처리 |
| 위원 배정 | 몫·나머지에 따른 연속 문항 구간 배정 | 빈 값·중복 식별자 검사. ReviewerAssignmentService는 최소 배정량 우선 방식 |
| 검토계획 | 분야·유형·문항의 트랜잭션 저장 | 저장소 인터페이스로 저장 단위 표현 |
| 문항번호 반입 | 기존 대상 삭제 후 등록, 실패 시 롤백 | 전체 번호 사전 검사, 빈 목록·중복 번호 차단 |
| 시험·외부 API | 답안·결과·오답노트·좌석 처리 | 제출·요청 ID 중복 검사, 상태 전이, 소유권·좌석 정책 |
| 수험표 | 응시·면제 표시와 사진·약도 자료 구성 | 가상 자료 ID와 존재 확인 함수 사용. 면제 자격 판정은 하지 않음 |

DB·캐시·외부 시스템은 메모리 저장소 또는 주입 함수로 대체하였습니다. 테스트 결과는 이 예제에 해당합니다.
