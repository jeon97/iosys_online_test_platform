# 담당 업무와 기여 내용

담당 업무와 원본 동작의 확인 범위는 [근거 문서](SOURCE-SCOPE.md)를 따릅니다. 코드 전체의 단독 개발이나 공개 예제에서 추가한 규칙을 과거 구현으로 간주하지 않습니다.

SVN 작업 사본에서 작성자 `joshuajeon`으로 확인되는 변경 파일과 실제 Controller, Service, Mapper 구조를 기준으로 정리하였습니다. 원격 SVN 로그가 안정적으로 조회되지 않아 커밋 수는 기재하지 않았습니다.

## 시험 결과 통계 관리

시험별 응시 현황을 조회하고 운영자가 결과 상태를 보정하는 기능을 개발하였습니다.

- 시험 기본정보, 검색 결과 건수, 응시자 목록을 함께 반환
- 수험번호와 시험 진행 상태를 이용한 검색
- 결시 상태 일괄 확정 및 확정 취소
- 화면에서 수정한 시험 통계 목록 저장
- 화면 조회와 엑셀 자료에 동일한 검색 조건 적용

구현은 화면 요청을 받는 Controller, 업무 조건과 저장 단위를 관리하는 Service, 통계 조회 전용 MyBatis Mapper로 나눴습니다.

## 부정행위 통계 관리

부정행위 의심 건을 유형별로 집계하고 운영자가 최종 내용을 보정하는 기능을 개발하였습니다.

- 유형별 건수와 상세 목록 분리 조회
- 부정행위 유형과 상세 내용 수정
- 판정 확정 및 확정 취소
- 목록 조회와 집계 조회 쿼리 분리

## 응시자 시험 관리

응시자가 본인의 시험과 처리 결과를 확인하는 기능을 개발하였습니다.

- 사용자 자격 종목 확인
- 응시 예정·완료 시험 목록 조회
- 시험별 접수 상세와 결과 조회
- 환불 요청과 추가 서류 제출 처리
- 인증 필터와 사용자 접근 경로 처리

## 검토계획 관리

문항 검토 계획에 분야, 문항 유형, 대상 문항을 연결하는 기능을 개발하였습니다.

- 같은 시험에 중복 검토계획이 생성되지 않도록 확인
- 출제계획의 분야·유형·문항을 검토계획으로 이관
- 분야와 유형 구성의 일괄 교체
- 검토 대상 문항 추가·삭제
- 엑셀 문항번호로 메타데이터를 확인한 뒤 일괄 등록

분야·유형·대상 문항의 변경을 트랜잭션으로 처리하였습니다. 공개 예제의 전체 사전 검증과 원본의 삭제·등록·롤백 순서는 구분하였습니다.

## 선정위원 배정

선정위원에게 담당 문항을 수동, 자동, 엑셀 방식으로 배정하는 기능을 개발하였습니다.

- 기존 배정은 수정하고 신규 배정은 추가
- 분야별 위원과 문항 목록을 이용한 자동 배정
- 전체 문항 수의 몫·나머지를 이용한 연속 구간 분배
- 엑셀의 분야, 문항번호, 사용자 ID 검증 후 일괄 반영
- 위원 배정 완료 여부와 배정 점수 관리

## 문항과 관리자 기능

- 문항별 사용 이력과 사용 통계
- 분야, 공통코드, 메뉴 관리
- 시스템 처리 이력 조회
- 운영 화면과 MyBatis Mapper 개발
