# 주요 처리 방식

## 통계 조회 조건

결과 목록, 전체 건수와 엑셀 다운로드에 같은 검색 조건을 적용하였습니다. 부정행위 유형별 집계와 상세 목록은 별도 조회로 구성하였습니다.

## 계획 구성의 일괄 변경

검토계획에 연결된 분야·문항 유형·대상 문항을 트랜잭션으로 변경하였습니다. 엑셀 문항번호의 메타데이터를 조회하여 검토 대상을 등록하고 오류 시 변경을 롤백하였습니다.

## 선정위원 자동 배정

문항 수를 위원 수로 나눈 몫을 기본 배정량으로 계산하고, 나머지는 앞 순서의 위원에게 한 문항씩 추가하였습니다. 각 위원에게 문항 순서를 유지한 연속 구간을 배정하였습니다.
